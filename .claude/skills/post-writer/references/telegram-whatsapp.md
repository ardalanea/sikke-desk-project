# Telegram and WhatsApp channel posts

## Telegram

- **Length:** 90–180 words (Light). Long threads only for features: 3–5 messages, each ending on a hook.
- **Limits:** text message up to 4,096 characters; a caption on a photo is much shorter (1,024 characters for most accounts), so posts with an image must stay short or put the text as a separate message.
- **Structure:**
  1. Bold grip line (Telegram supports **bold**).
  2. 2–4 short paragraphs telling the story.
  3. The twist or lesson in one line.
  4. Light prompt (a question or "forward this to the friend who…").
  5. Source line: `Source: <short name>` (links allowed).
  6. Sign-off + 2–3 hashtags.
- Farsi Telegram audiences read long-ish posts; Farsi version may run up to 220 words if the story needs it.

## WhatsApp channel

- **Length:** 40–100 words (Feather). Many readers see it as a notification preview; the first 1–2 lines must carry the whole hook.
- **Formatting:** WhatsApp uses `*bold*` and `_italic_`. Keep paragraphs to 1–2 lines.
- **Structure:** grip line → 2–3 lines of story → twist → `Source: <name>` → short sign-off. No hashtags (they don't work there).
- Can link to the full Telegram or Instagram post for the longer version.
