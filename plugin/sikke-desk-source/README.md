# Sikke Desk (by TEA Media)

**Sikke** means *coin* in Turkish (sikke) and Farsi (سکه). The desk produces "money's strangest true stories" for social channels in English, Farsi and Turkish, held to magazine-grade fact-checking.

## What to say to it

| You say | What happens |
|---|---|
| "Run the Sikke desk" / "make the next edition" | Full cycle: plan, research, verify, write all platforms in 3 languages, standards check, edition pack for approval |
| "Plan the next two weeks" | Story budget only (anniversaries, news pegs, archive gaps) |
| "Find facts about Ottoman money" | One reporter desk digs and returns fact cards |
| "Fact-check this" | Independent verification of a card or draft |
| "Turn card ANT-0012 into posts" | Writes all platform posts from a verified card |
| "What do we have on Iran?" | Searches the fact archive |

## Team

**Skills (playbooks):** sikke-editor (editor-in-chief), story-budget, fact-hunter, fact-card, fact-verify, money-converter, archive-keeper, sikke-voice (the "reader load" rule), post-writer, trilingual-localizer, standards-check, visual-brief.

**Agents (staff):** 8 beat reporters (antiquity, empires-crashes, cons-heists, crypto, money-lock, oddities-myths, region, wire), plus fact-checker, fa-editor, tr-editor, standards-editor.

## Capacity

Default is **2 editions per week**. Each edition = 1 lead story → Telegram/WhatsApp post, Instagram/Facebook carousel + caption, short reel script, LinkedIn post → each in EN, FA, TR. Change the pace anytime ("go to 5 a week", "daily wire posts"); the editor scales the number of desks it dispatches. See `skills/sikke-editor/references/capacity.md`.

## Files it creates

In the folder you work in: `sikke/archive/fact-archive.csv` (every verified fact), `sikke/cards/` (one file per card), `sikke/editions/` (one pack per edition, ready to post).
